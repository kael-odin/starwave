# 星潮 Starwave · 视觉与体验设计

## 1. 概念

**深海纸面，星标为记。**

星潮不是终端黑客风，也不是 GitHub 官方紫。它像一份每天更新的远洋观测日志：纸面温暖、文字克制、数字精确，偶尔有一枚星标金指向真正值得看的东西。

三个关键词：

- **编辑感**：标题、摘要、判断句是主角，不是卡片阴影和渐变。
- **数据感**：星速、排名、版本、license 用等宽字，数字可核对。
- **潮汐感**：星速曲线、榜单升降、周更节奏；动效只服务于“变化”。

### 2.3 用色规则

- 一屏最多一个强调色区域；橙色只给“上升/新/热点”，金色只给 star 和榜单名次。
- 不用渐变做大面积背景；sparkline 下可以有一层 8% 透明度的面积填充。
- 正文对比度 ≥ WCAG AA；`--ink-4` 只用于 12–13px 元信息。

## 3. 字体

- 中文正文：系统无衬线（PingFang SC / HarmonyOS Sans SC / Microsoft YaHei）。
- 数字、star 数、排名、版本、license：等宽（`ui-monospace` / SF Mono / Consolas）。
- 标题：同族无衬线，字重 650，`letter-spacing: -0.01em`；不引入重型中文 Web 字体，避免首屏抖动。
- 英文：system-ui / Inter fallback；不做全大写长句。
- 行高：正文 1.75；卡片摘要 1.65；标题 1.25。

## 4. 布局

- 桌面：左侧栏 236px（继承 AIHOT shell），内容区最大 1200–1440px。
- 首页双栏：主栏（精选流）+ 右栏（本周星榜、新星榜、日报）。
- 移动：底部 tab（精选 / 全部 / 仓库 / 星榜 / 我的）。
- 卡片圆角 12px，面板 14px，按钮 8px；发丝线 1px，不用重阴影。
- 留白：区块间距 32–48px；卡片内边距 16–20px。

## 5. 签名组件

### 5.1 StarSparkline

- 7/30 日 star 曲线，宽 96–160px，高 28–40px。
- 线上一点标出最新值；上升用 `--hot`，下降用 `--ink-4`。
- 旁边 mono 文本：`+1,248 / 7d`。
- 无数据时显示 `—`，不画假线。

### 5.2 RepoCard

```
┌─────────────────────────────────────────────┐
│ owner/name                        ★ 12.4k  │
│ 一句话描述，最多两行                          │
│ Rust · MIT · 3 天前更新      ▁▂▃▅▆▇ +1.2k/周 │
│ [编辑推荐 86] [本地优先] [CLI]               │
└─────────────────────────────────────────────┘
```

- 标题可点击进仓库档案；右上 star 数等宽。
- 标签最多 3 个，超出显示 `+n`。
- 有入选理由时，卡片底部一行引用式判断。

### 5.3 RankRow

```
01  owner/name                  ★ 24.1k   +4,218 / 7d
    把本地模型网关做成菜单栏应用   HN 326 分 · 编辑 86
```

- 名次用 mono，01–03 用星标金，其余 `--ink-4`。
- 理由必须存在；没有理由不显示。

### 5.4 StarMeter（星潮指数）

- 0–100 的横向刻度，分段着色：0–40 灰、40–70 青、70–100 金。
- 旁边一句解释：`星速 92 · 社区 78 · 编辑 86`。

### 5.5 Verdict（一句话判断）

- 仓库页头部下方，18–20px，最多两行。
- 左侧一条 2px 深海青竖线；不是引用块，不用斜体。

### 6.3 星榜

- Tabs：日榜 / 周榜 / 月榜 / 新星榜
- 顶部说明：统计窗口、更新时间、算法入口
- 每行：名次、仓库、star、增量、理由、标签
- 右侧：榜单说明 + “为什么不是按总 star 排”

## 7. 动效

- 页面进入：卡片 120ms 淡入 + 4px 上移；同屏最多 12 个，避免长列表全动。
- 星速曲线：首次绘制 400ms path 动画；切换周期时 morph。
- 排名变化：上升箭头 160ms；不做数字滚动。
- 尊重 `prefers-reduced-motion`。

## 8. Logo 与字标

- 图形：一条向右上扬的潮线，在波峰处嵌一枚四角星；单色可用。
- 字标：`星潮` 粗体 + `STARWAVE` 小号字距 0.18em。
- 图标：深海青底 + 米白潮线星；深色底用反白。
- 文件：`site/brand/logo.svg`、`wordmark.svg`、`wordmark-dark.svg`、`icon.svg`，PNG 由脚本生成。

## 9. 分享图

- 1080×1080 / 1200×630。
- 底色 `#0A0F14`（夜航）或 `#F7F5EF`（纸面）。
- 左上：星潮 Logo；右上：日期。
- 主标题 2 行，最多 18 字/行；下方一条星速曲线 + `本周 +12,438 stars`。
- 右下：`starwave` 域名。

## 10. 文案语气

- 说人话，不用“重磅、炸裂、颠覆、必看”。
- 判断句要有主语和依据：`它把 X 做成 Y，适合 Z`。
- 不替读者做决定：`值得试` 而不是 `你必须用`。
- 数字给时间窗口：`7 天 +4,218 stars`，不写 `暴涨`。
- 英文自然，不逐字翻译中文标题。
