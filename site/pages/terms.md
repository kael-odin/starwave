## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，可能有误，重要信息请以原文为准。原文版权归各来源所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。

## 2. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过反馈页联系我们，我们会尽快处理。

## 3. 使用本站的数据

个人阅读、组织内部使用和课题研究免费；商业产品、公开转载、批量再分发、模型训练语料需要事先取得书面同意。引用时请保留原文链接和星潮的页面地址。

## 4. 与 GitHub 的关系

星潮是独立的第三方项目，与 GitHub, Inc. 没有隶属、赞助或背书关系，不使用 GitHub 的 Logo 暗示官方身份。站内展示的仓库信息来自 GitHub 公开 API 和公开页面，具体以 GitHub 为准。

## 5. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 Retry-After，不要并发重试。

## 6. 免责

本站按“现状”提供，不保证内容完整、准确和持续可用。模型生成的摘要可能有误，重要信息请以原文和仓库本身为准。
